# Helix Core v3.0.0

Helix Core v3.0.0 is the first complete open-source release of the desktop
computational drug-discovery platform.

## Downloads

- `HelixCore-3.0.0-portable.exe` — self-contained Windows 10/11 x64 desktop
  application. On first launch it extracts to `%APPDATA%\HelixCoreApp`; later
  launches reuse that verified cache.
- `helixcore-tools-win-x64.zip` — the exact AutoDock Vina 1.2.6 and Open Babel
  3.1.1 tool bundle used by the Windows release and the reproducible source
  installation workflow.
- `SHA256SUMS.txt` — SHA-256 checksums for both release assets.

Verify a download from PowerShell:

```powershell
Get-FileHash .\HelixCore-3.0.0-portable.exe -Algorithm SHA256
```

Compare the result with `SHA256SUMS.txt` before running the application.

## What is included

- Structure retrieval, cleanup, receptor and ligand preparation
- AutoDock Vina docking and batch virtual screening
- Pose, interaction, similarity, clustering, and descriptor analysis
- Drug-likeness filters, PAINS checks, and curated structural alerts
- Analog generation, scaffold hopping, fragment-based design, and
  pharmacophore workflows
- Project management, results comparison, watchlists, and report generation
- A local FastAPI service with documented HTTP and WebSocket interfaces

Helix Core is an integration and orchestration layer over established
open-source scientific engines. It does not introduce a new scoring function or
claim predictive superiority.

## Verification completed

- 155 backend tests passed
- 43 Electron end-to-end tests passed
- The frozen backend executable passed live health-endpoint testing
- The packaged Electron application passed launch, backend-readiness, and clean
  shutdown testing
- Every file in the scientific-tools archive was verified against
  `tools_manifest.json`
- Repository secret and private-material scans reported no findings

The latest React Router package reports an npm advisory for React Server
Components action handling. Helix Core is a static Electron single-page
application and does not use React Server Components or server actions, so the
affected path is not present. Remaining electron-builder audit findings are in
build-only dependencies and are not shipped in the application runtime.

## Windows signing notice

This community release is not Authenticode-signed. Windows SmartScreen may
therefore display an “unrecognized app” warning. Verify the SHA-256 checksum
before choosing **More info → Run anyway**. No security warning should be
disabled system-wide.

## Reproducibility and licensing

## Scientific-use notice

Helix Core is research software. Descriptor filters, heuristic rankings,
docking scores, and generated structures are computational aids—not clinical,
diagnostic, safety, efficacy, or regulatory conclusions. Results require
independent expert review and experimental validation.
